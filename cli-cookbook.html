CLI cookbook

The jxl_cli binary decodes and benchmarks JPEG XL files. Build it from the workspace:

cargo build --release --bin jxl_cli

Decode a file

target/release/jxl_cli input.jxl output.png

Output formats: PNG, PPM, PGM, APNG and EXR.

Print image metadata

target/release/jxl_cli input.jxl --info

Benchmark decoding speed

target/release/jxl_cli input.jxl --speedtest --num-reps 10

Conformance and bug reports

The project strives to decode all conformant JPEG XL bitstreams correctly. If an image decodes with the reference implementation djxl (from libjxl) but fails or renders incorrectly with jxl-rs, open an issue with the bitstream attached.
