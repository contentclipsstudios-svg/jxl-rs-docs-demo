FAQ

Is jxl-rs the official JPEG XL implementation?

No. libjxl (C++) is the official ISO/IEC 18181-4 reference software. jxl-rs is a pure-Rust implementation developed within the JPEG XL project; it aims for full specification conformance, and it is the JPEG XL decoder used in Google Chrome / Chromium and Mozilla Firefox.

How does its performance compare?

The performance closely matches — and sometimes exceeds — the C++ reference implementation, while having improved support for progressive rendering and lower memory requirements.

Is it memory safe?

The vast majority of the code is safe Rust. Where unsafe is needed for performance benefits (including SIMD), it must carry extensive safety comments and be reviewed by a non-author unsafe Rust expert.

Where do I report a decoding bug?

Open an issue with a bitstream that decodes with djxl but fails with jxl-rs. See the CLI cookbook for the workflow.

How do I contribute?

See CONTRIBUTING.md for contribution guidelines and CLA requirements, and join the JPEG XL Discord to talk to the community.

What is JPEG XL?

A still-image codec standardized in 2022 as ISO/IEC 18181. More at jpeg.org/jpegxl and jpegxl.info.
