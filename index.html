jxl-rs user guide

jxl-rs is a high-performance, conforming and memory-safe JPEG XL decoder written in pure Rust. It is the JPEG XL decoder implementation used in Google Chrome / Chromium and Mozilla Firefox, developed within the JPEG XL project and aiming for full conformance to ISO/IEC 18181.

This site exists because of a gap: the crate's docs.rs page lists a dozen modules with no context, and issue #1001 asks for exactly what a docs site should provide — a documented path a new user can follow.

Where to start

  • New to the crate? Start with Getting started — install the library or the CLI and decode your first image.
  • Writing Rust code against the decoder? Read The decode path — the api/image/error surface, in the order a decoder actually uses it.
  • Decoding from the terminal? The CLI cookbook covers decode, metadata and benchmarks with jxl_cli.
  • Questions? See the FAQ — jxl-rs vs libjxl, conformance, reporting bugs.

What this site is

An unofficial documentation demo, built with Quillmark (a Markdown-to-site generator) as a proof of concept for #1001. It is not affiliated with the jxl-rs project; the API reference on docs.rs remains the source of truth for item-level signatures.
