Getting started

Install the library

The decoder ships as the jxl crate:

cargo add jxl

To decode through the image crate's format-agnostic loading APIs, add the integration crate and register the JPEG XL decoder:

[dependencies]
image = "0.25"
jxl-image-rs-integration = "0.6"
jxl_image_rs_integration::register_image_decoding_hook();

let decoded = image::open("input.jxl")?;
# Ok::<(), image::ImageError>(())

Registration enables both .jxl extension handling and automatic detection of bare codestreams and JPEG XL containers.

Build the CLI

The jxl_cli crate is the CLI decoding and benchmarking tool:

git clone https://github.com/libjxl/jxl-rs
cd jxl-rs
cargo build --release --bin jxl_cli

First decode

target/release/jxl_cli input.jxl output.png

Supported outputs include PNG, PPM, PGM, APNG and EXR. Continue with the CLI cookbook for metadata and benchmarking, or The decode path for the library API.
